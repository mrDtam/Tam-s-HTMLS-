# Tam's HTML Math Apps

A private collection of browser-based drill apps and educational tools hosted for St. George's School (SGS) Math and elementary learners. 

*   **High School:** Unit-specific skill drills (Levels 1–7) for Math 8 through Calculus 12. Features instant feedback and distractor analysis for common misconceptions.
*   **Elementary:** Child-friendly foundational math apps.
*   **Teacher Tools:** Internal interfaces for the AI LaTeX assessment Prompt Builders.

Built with Vanilla HTML/JS and KaTeX for math rendering. No logins, no tracking, just practice.
